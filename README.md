# Colección Barbie - App

Una aplicación móvil y backend diseñada para registrar, administrar y visualizar una colección de muñecas Barbie, con reconocimiento de imágenes mediante IA.

## 📱 Tecnologías
- **Frontend**: Flutter (Dart) - Aplicación móvil (Android/iOS)
- **Backend**: Django (Python) con Django REST Framework y PostgreSQL
- **Integraciones**: Reconocimiento de imágenes (OpenAI Vision API).

## 🗂 Estructura del Proyecto
- `/frontend`: Contiene todo el código de la aplicación móvil (Flutter).
- `/backend`: Contiene la API REST (Django) y la configuración de la base de datos.
- `/backend/docs`: Documentación detallada sobre la instalación y el despliegue.
